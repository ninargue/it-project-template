# Documentación del Proyecto

Esta carpeta está reservada para la documentación generada durante el ciclo de vida del proyecto:

- **`prd/`**: Documento de Requerimientos de Producto (PRD) y alcance consensuado.
- **`backlog/`**: Historias de usuario INVEST y tickets técnicos atómicos con sus criterios de aceptación.
- **`config-project-orchestrator/`**: Configuración de herramientas y metodologías de issues del equipo.

> 💡 Si utilizas el plugin orquestador (`/it-project-orchestrator`), esta estructura y sus documentos se generarán de forma guiada y automática.
